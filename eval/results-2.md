## 시간 및 처리 조건

test3 첫 골의 실제 시각과 감지 시각은 표시된 소수점 둘째 자리 기준으로 모두 13.47초다. 이 차이는 영상 시간축의 시각 차이며, 실제 처리 시간이나 스피커 해설 출력까지의 지연은 포함하지 않는다. 다른 영상의 실제 골 시각은 초 단위로 입력했으므로 감지 시각과의 차이를 정밀 지연 시간으로 사용하지 않는다.

## 별도 연동 시험

감지기, 백엔드, 점수판과 해설의 연동을 별도 Windows 영상에서 시험했다. 해당 영상은 위 5편의 합계에 포함하지 않았다.

- 전체 프레임 분석: 실제 골 7개 중 4개 감지, 3개 누락, 오탐 3개. CPU 약 5.6fps.
- 원래 영상 속도 분석: 실제 골 7개 중 1개 감지, 6개 누락, 오탐 2개. 전체 3,525프레임 중 2,926프레임을 건너뛰었다.
- 사전 분석 결과 재생 시 신호 7건 중 6건이 점수판에 반영됐다. 17.14초 신호는 11.84초 신호 이후 백엔드의 같은 골대 10초 제한에 걸렸다.
